# The public site: every file the build (dist/) must hold, and nothing else.
#
# The Worker serves dist/ (wrangler.jsonc, "assets"). The build (npm run build) fails when dist/
# holds a file that is not listed here or allowed by the pattern below, or is missing a listed
# one (ops/postbuild.mjs), and tests/assets.test.mjs proves wrangler would upload exactly this.
# So a new page or file is public only once its line is here.
#
# Each line is a path inside dist/. A line starting with "re:" is a regular expression that
# allows a whole family of files: the build's content-hashed output under _astro/ (scripts,
# the stylesheet, fonts, pictures, clips), which changes name whenever its content changes.
# dist/_headers is not listed: wrangler reads it as configuration and never serves it.
